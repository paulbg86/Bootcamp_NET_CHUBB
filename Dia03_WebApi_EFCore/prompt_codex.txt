# Prompt Codex - Día 3: ASP.NET Web API + EF Core
Genera una Web API (.NET 8) con:
- DbContext para SQL Server y entidad Product(Id, Name, Price)
- Controlador ProductsController con CRUD
- Serilog y Swagger configurados
- appsettings.json con ConnectionStrings
Produce un proyecto compilable con `dotnet run`.
