# Prompts Globales para Codex (VS Code / Codex CLI)

## Día 1 – C# Moderno
Genera un programa en C# .NET 8 que demuestre records, pattern matching, async/await y LINQ avanzado, con ejemplos en consola.

## Día 2 – WCF (CoreWCF)
Crea 3 proyectos (.NET 8): ServiceLibrary (CoreWCF), WcfHost (ASP.NET Core host con endpoint basicHttpBinding), WcfClientConsole (cliente con ChannelFactory). Incluye README con pasos.

## Día 3 – Web API + EF Core + Serilog + Swagger
Crea una Web API con EF Core (SQL Server), entidad Product y CRUD, Serilog para logs, Swagger habilitado.

## Día 4 – Docker + Azure DevOps
Genera Dockerfile multi-stage y pipeline YAML para compilar, testear, construir imagen y publicar a ACR.

## Día 5 – Seguridad JWT
Agrega endpoints /api/auth/login (retorna JWT) y /api/auth/secure (protegido). Configura JwtBearer y Swagger con Authorization.

## Día 6 – Logging + Testing
Añade Serilog a consola e implementa pruebas xUnit. Expón cómo ejecutar `dotnet test` y medir cobertura.

## Día 7 – Documentación
Compila un README completo de arquitectura, configuración, ejecución y despliegue.
